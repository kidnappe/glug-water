# 设置页排版规范

> 来源：抖音《第 5 集：AI 做的设置页太乱？三步排版清楚》@费纸张，合集「AI 设计技巧分享」，44 秒。
> 本文根据视频画面整理，用于咕嘟设置页改版，也可作为其他项目的设置页检查清单。

## 核心结论

AI 生成的设置页“看着怪”，主因通常不是配色，而是排版：名称和控件没有对齐、框套框、分组没有层次。

## 三步排版法

### 第一步：一项设置占一行，名称在左、控件在右

- 一行只放一项设置，不要一行塞多个控件。
- 所有名称共用一条左对齐线，所有控件共用一条右对齐线。
- 控件放右边（开关、下拉、步进器、箭头或当前值），不要让名称在上、控件在下再单独包一层盒子。
- 名称要短；需要解释时用第二行小字，不要拉长标题。

### 第二步：去掉最外面那层多余的框

- 页面背景本身已经是容器，不要再把整个设置页套进一张大卡片。
- 避免“卡中卡、框套框”；分组卡片可以保留，但外层大框要去掉。
- 减少装饰性边框和底色，让内容本身成为层次。

### 第三步：分组、加标题、控制留白节奏

- 按功能分组，每组加一个小标题（如「阅读」「同步与下载」「存储」）。
- 组内：行距收紧，行与行之间只留细分隔线。
- 组间：留白明显大于组内，让分组一眼可见。
- 删除、清空、重置等危险操作单独放一组或页面底部，不要混在普通设置里。

## 例外：表单不能照搬

设置页的左右排不适用于注册、结账等表单场景。

| 场景 | 布局 | 适用原因 |
| --- | --- | --- |
| 设置页 | 名称在左，控件在右 | 名称短、控件小、每项独立保存 |
| 注册 / 结账表单 | 名称在上，输入框占满整行 | 用户按顺序填写，错误提示需要空间，内容可能较长 |

表单若也用左右排，输入框和错误提示会被挤在半列里，很难用。

## 自检清单

- [ ] 每一项设置独占一行。
- [ ] 名称左对齐线一致，控件右对齐线一致。
- [ ] 页面没有多余的“外层大卡片”。
- [ ] 每个分组有标题，组间留白大于组内。
- [ ] 组内用细分隔线，最后一行不画线。
- [ ] 危险操作单独分组，视觉上与普通设置区分。
- [ ] 输入类表单没有照搬左右排。

## 咕嘟设置页落地

按上述规范，设置页分为 7 组：

| 分组 | 内容 |
| --- | --- |
| 账户 | 我的头像、我的昵称、在线排行榜 |
| 饮水目标 | 每日目标、自定义水量 |
| 提醒 | 喝水提醒、提醒周期、提醒时段、吃药提醒 |
| 显示与交互 | 深色模式、导航栏样式、重力水杯、特效说明 |
| 数据与设备 | 连接手表、立即同步、断开手表、断开排行榜、导出数据、导入数据 |
| 关于 | 检查更新、关于应用 |
| 危险操作 | 重置所有数据 |

实现要点：

- 组标题在卡片外，卡片只包住同组设置行。
- 每行左侧图标 + 名称，右侧显示当前值、开关或箭头。
- 行与行之间用 `--border-light` 细分隔线，最后一行无线。
- 组间距 24px，组内行高 13px，形成“组内紧、组间松”的节奏。
- 「重置所有数据」从原来的大红按钮改为独立「危险操作」组中的红色行。
