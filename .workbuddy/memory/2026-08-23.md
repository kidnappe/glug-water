### 背景
App（Android WebView 套壳）把 index.html 焊死在 APK assets 里，网页更新必须重新构建。用户拍板采用「版本检查热更新」方案。

### 方案要点
- **网页侧**（web 分支）：`build-www.py` 一键生成 `version.txt`（内容 = APP_VERSION）+ `www.zip`（index.html + sw.js + manifest.json + icons/ 完整资源树，59 条目，385KB），提交推送后 GitHub Pages 自动部署
- **Android 侧**（app 分支）：`MainActivity.java` 启动先加载本地可用版本（私有目录已下载版 > 内置 assets 版），后台异步检查远程 version.txt，有新版则下载 www.zip → 解压到临时目录 → 原子替换 filesDir/www → reload。失败静默回退，绝不影响启动
- 关键设计：仍走 file:// 协议，Android WebView 中所有 file:// 页面共享同一 origin 存储 → **数据无缝保留，无迁移**
- `sync-www.bat` 改为同步整个 www 目录；assets/www 从单文件 index.html 升级为完整树（与 web v2.3.0 对齐）
- 版本：app v2.1.2 → v2.2.0（versionCode 6→7）

## v2.3.1 应用图标重绘（用户拍板：A 结构 + D 配色 → 修正为 A 深底 + D 宽杯型）

### 设计
- 4 候选方案：A 水青玻璃杯 / B 一滴水 / C 涟漪 / D 浅底暖杯
- 用户指令迭代：先 "a 的核心元素改为 d" → 浅底水青杯 → "背景颜色用 a 的啊" → 改为深水青底 + D 的宽杯型（杯身 x:52-140, 88 宽）+ 白色杯身
- 理由：深底更饱满，杯型加宽后图标占比更大
- Web SVG（4 个）：viewBox 0 0 192 192 统一内容，矢量缩放

### 落地
- PNG 导出：Edge headless --screenshot 截 HTML img 包装器（直接截 SVG 被裁切，因为 Edge 不自动缩放 SVG 适配窗口）
- manifest theme_color #4A90E2→#0FA896，background_color #f0f4fb→#0C7A6B
- Android launcher XML：background 渐变 #0FA896→#0C7A6B，foreground 白杯限制在 18-90 安全区（避开启动器圆形遮罩裁切）
- 版本：APP_VERSION v2.3.0→v2.3.1，SW_DEPLOY 20260823→20260823a（同日后缀避免冲突），versionCode 7→8，versionName 2.2.0→2.2.1
- 提交：web 8c4dc2a（13 文件），app d5fa374（14 文件）
